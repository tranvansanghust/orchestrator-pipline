# T2: POST /auth/register

- Requirements: FR-1
- Depends on: T1
- Areas: auth

## Goal

Let a visitor create an account.

## Contract

- `POST /auth/register` per `operationId: register` in 04-api-spec.yaml.
- `services/auth.register(email, password)` hashes with bcrypt cost 12 and
  calls `createUser` from T1.

## Acceptance tests

- `test/auth.register.test.ts` — 201 with `User` shape and no secret fields;
  409 on case-insensitive duplicate; 422 on bad email, short password or
  extra fields; stored hash is bcrypt cost ≥ 12.

## Out of scope

Login, tokens, email verification.

## Notes

NFR-2: never log the request body of this route.
