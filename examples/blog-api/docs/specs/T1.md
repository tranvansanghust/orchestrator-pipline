# T1: User model + users migration

- Requirements: FR-1
- Depends on: none
- Areas: migration

## Goal

Create the `users` table and a user model that the auth tasks build on.

## Contract

- Table `users` exactly as in 05-data-model.md.
- `src/models/user.ts` exports:
  - `createUser(email: string, passwordHash: string): Promise<User>`
  - `findUserByEmail(email: string): Promise<(User & { passwordHash: string }) | null>`
  - `User` matches `components.schemas.User` in 04-api-spec.yaml.
- Email lookups are case-insensitive.

## Acceptance tests

- `test/user.model.test.ts` — insert/read round trip; case-insensitive
  duplicate rejected; `createUser` result has no `passwordHash`.

## Out of scope

Hashing (T2), HTTP routes, posts.

## Notes

Migration file: `migrations/0001_create_users.sql`, with a down migration.
