# T4: Post model + posts migration + POST /posts

- Requirements: FR-3
- Depends on: T3
- Areas: migration

## Goal

Let an authenticated user publish a post.

## Contract

- Table `posts` and its index exactly as in 05-data-model.md.
- `POST /posts` per `operationId: createPost` in 04-api-spec.yaml, protected
  by `requireAuth` from T3.
- `author_id` comes from `req.userId` only.

## Acceptance tests

- `test/posts.create.test.ts` — 201 with author from token; 401 without or
  with expired token; body `author_id` has no effect; 422 on empty or
  201-char title.

## Out of scope

Listing (T5), editing, deleting.

## Notes

Migration file: `migrations/0002_create_posts.sql`, with a down migration.
