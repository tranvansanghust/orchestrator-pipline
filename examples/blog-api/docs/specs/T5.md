# T5: GET /posts with cursor pagination

- Requirements: FR-4
- Depends on: T4
- Areas: none

## Goal

Public, paginated listing of posts, newest first.

## Contract

- `GET /posts` per `operationId: listPosts` in 04-api-spec.yaml.
- Keyset pagination on `(created_at DESC, id DESC)`; `next_cursor` is an
  opaque string encoding both, `null` on the last page.

## Acceptance tests

- `test/posts.list.test.ts` — ordering, default and max `limit`, 422 on
  `limit=51` and malformed cursor, no gaps/duplicates when timestamps tie,
  works without a token.

## Out of scope

Filtering, search, per-author listing.

## Notes

NFR-1 is checked at the integration build, not in this task's tests.
