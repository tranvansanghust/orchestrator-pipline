# T1: API: count open todos

- Requirements: FR-1
- Repos: api

## Goal

`api/src/count.sh` defines `open_count [file]` (default `data/todos.txt`,
relative to `api/`): prints the number of lines that do not start with `[x]`.

## Acceptance tests

- `api/test/count.sh`: the cases in the test plan, using temporary files.

## Out of scope

Anything in `web/`.
